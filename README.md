💧 PURI BOMBA – Sistema Web de Gestión de Pedidos
📌 Descripción

PURI BOMBA es un sistema web desarrollado como proyecto integrador, enfocado en la digitalización de procesos de una empresa dedicada a la venta y distribución de agua purificada.

El sistema permite gestionar pedidos, clientes y promociones a través de una plataforma accesible desde cualquier navegador, mejorando la organización interna del negocio y la experiencia del usuario.

🚀 Objetivo del Proyecto

Desarrollar e implementar una aplicación web que permita:

Gestionar pedidos de agua purificada
Administrar clientes y usuarios
Mostrar productos y promociones
Mejorar la comunicación entre la empresa y sus clientes

🏗️ Arquitectura del Sistema

El sistema está basado en una arquitectura cliente-servidor, donde:

El cliente interactúa mediante el navegador
El servidor procesa la lógica del sistema
La base de datos almacena la información
📊 Problema que Resuelve

Muchas pequeñas empresas aún manejan pedidos de forma manual, lo que genera:

Falta de control
Errores en pedidos
Retrasos en entregas
Mala comunicación con clientes

PURI BOMBA soluciona esto mediante una plataforma digital que centraliza y automatiza estos procesos.
