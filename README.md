# PURI-BOMBA-Sistema-Web-de-Gesti-n-de-Pedidos
PURI BOMBA es un sistema web para la gestión de pedidos de agua purificada. Permite registrar clientes, administrar productos, controlar pedidos y mostrar promociones. La plataforma mejora la organización del negocio, optimiza la atención al cliente y facilita la digitalización de procesos tradicionales.
